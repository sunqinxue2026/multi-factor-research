## 3. 总体研究流程与接口边界

```text
历史多股票行情 → 日期对齐 → 因子计算 → 因子预处理
→ IC/RankIC及分组分析 → 多因子评分 → 定期选股及目标权重
→ 项目一回测接口适配 → 绩效分析 → CSV及图表研究报告
```

未来收益标签只用于研究评价，不得进入当期因子、标准化、评分和选股。数据来源、复权口径、股票池范围、交易日历、信号与执行时点必须明确。

复用项目一行情格式与指标定义，不复制其完整回测引擎。项目一当前单股票引擎不能直接承担多股票共享现金组合；第六、七阶段必须先确认统一组合接口与必要扩展方案，不能用多个独立单股账户平均冒充共享现金组合。

## 4. 功能需求

### 4.1 金融数据读取与整理

兼容以下八列CSV，并支持多股票批量读取：

```csv
symbol,trade_date,open,high,low,close,volume,amount
```

要求：

1. 股票代码作为字符串保留前导零；按股票、交易日期整理，联合键唯一。
2. 检查字段、日期、数值、价格关系及重复冲突，不静默修正非法数据。
3. 使用显式交易日历对齐，不将普通工作日或股票已有报价集合当作权威日历。
4. 区分字段缺失、记录缺失、真实零值；不自动补价格、成交量或成交额。
5. 停牌、上市等状态需要外部事实；资料缺少时为未知，不能仅凭缺价或零成交推断。
6. 明确来源、截至日期、单位和复权口径；当前数据层采用CNY／股／CNY，不自动换算。
7. 建立多股票长表和单日横截面查询结构，保留可追溯信息。
8. 不将全样本股票集合视为历史可投资股票池；没有历史成分股和退市数据时，报告必须披露幸存者偏差。

### 4.2 基础因子

每只股票独立、按显式日历位置计算，仅使用当日收盘及此前数据；窗口不足或缺价保留无效值及原因，不以0替代。支持20、60及可配置窗口。

设 C(s,t) 为统一口径收盘价，N为回看窗口：

- 动量：`C(s,t) / C(s,t-N) - 1`。N个收益间隔需要N+1个价格；当前已确定契约要求整个窗口连续有效。
- 日收益：`C(s,t) / C(s,t-1) - 1`，不隐式填充价格。
- 波动率：最近N个日收益的样本标准差，`ddof=1`；年化乘`sqrt(A)`，默认A=252。当前窗口要求N≥2。
- 均值反转原始量：`C(s,t) / mean(C(s,t-N+1:t)) - 1`，保存原始均线偏离值；方向统一属于预处理，不在原始因子中隐藏翻转。

必须解释因子经济含义及方向假设。价格统计有效不代表可投资；波动率高低、动量强弱或负偏离均不能直接解释为确定收益。

### 4.3 因子预处理

实现缺失检查、异常识别、分位数截尾或Winsorize、同日横截面Z-score、方向统一及处理记录。

- 区分时间序列处理和横截面处理，不用全样本统计量改写历史。
- 记录截尾阈值、均值、标准差、方向、样本数和无效原因。
- 公式：`z(s,t) = (x(s,t)-mean_t) / std_t`。
- 截尾边界、最小样本、标准差自由度、零方差和状态筛选规则在第四阶段前确认。
- 当前候选方向为动量+1、波动率−1、原始偏离−1，仅是研究假设，须确认并接受后续检验。

### 4.4 IC与RankIC

逐日计算因子与明确持有周期未来收益的横截面相关性：

- IC：Pearson相关系数。
- RankIC：Spearman秩相关系数，明确并列秩处理。
- 输出每日值、有效样本数、均值、标准差、ICIR、IC正值比例和无效原因。
- ICIR为均值／标准差；自由度、是否年化须明确记录，不能擅自混用。
- 支持未来5日、20日等可配置评价周期，明确入口和出口价格及交易日位置。
- 收盘后因子不能假设同一收盘价可成交；标签评价口径与可执行账户收益分开。
- 样本不足、常量截面、零标准差及样本尾部标签缺失必须显式处理。

未来收益具体入口、出口及门槛属于第五阶段前待确认规则；设计候选不等于负责人已确认。

### 4.5 因子分组收益

- 每个交易日独立按因子排序，支持五组或十组。
- 处理股票不足、并列值、空组和无效标签，记录每组股票数。
- 输出每组平均未来收益、累计收益、风险、高低组差和多空收益，绘制曲线。
- 多空研究收益不等于可实际卖空账户收益，须标明成本和执行假设。
- 重叠多日未来收益不得直接逐日复利成净值；采用经确认的非重叠评价或独立日度组合口径。

### 4.6 多因子组合

- 将三个因子家族经过标准化、方向统一后线性加权，提供等权基准及自定义权重。
- 输出综合评分、股票排名和Top N选择。
- 明确缺失因子、权重归一化、负权重及同分边界规则。
- 20/60是窗口选择，不默认将同家族多个窗口当作独立等权因子。
- 第一版不引入复杂机器学习、深度学习或自动权重优化。
- 如果未来增加权重优化，必须保留等权基准、分离训练和验证区间，不以全样本结果挑选最优参数。

### 4.7 定期调仓

- 支持每周或每月调仓、Top N选股、等权目标配置及股票退出。
- 明确信号日、调仓日、实际执行日，不以收盘后信息在同日收盘成交。
- 支持手续费、滑点，记录调仓前后持仓和实际成交差异。
- 计算换手率，明确单边或双边、目标权重或实际成交、资金分母及首次建仓口径。
- 共享现金、整手、先卖后买、费用预留、停牌和缺价、未成交及剩余现金规则实施前确认。

### 4.8 回测接入与绩效

通过统一接口接入项目一，不复制完整引擎；公共接口改变须检查调用方并回归项目一相关测试。若涉及数据库结构改变，先说明迁移、兼容和回滚影响。

输出累计收益、年化收益、年化波动率、最大回撤、夏普、换手率、IC、RankIC、多空研究收益。账户类指标与项目一定义对齐，尤其年化天数、日收益起点、回撤初始基准及无风险利率口径；研究相关性与账户绩效分开存储和解释。

### 4.9 可视化与研究报告

使用Matplotlib生成：IC时间序列与分布、RankIC时间序列、因子相关性热力图、分组曲线、组合净值、回撤、调仓和换手统计。

导出研究CSV及图表，记录输入摘要、来源、日历、参数、因子方向、权重、评价周期、运行时间、环境和限制。不得伪造收益、性能或检验结论。
