# 轻量界面使用说明

## 定位与启动

这是八阶段系统之外新增的轻量展示层，使用Streamlit，不改变原有研究公式和执行规则，不提供实盘交易、账号管理或远程部署。安装可选依赖后，在项目根目录执行：

```powershell
python -m pip install -r requirements-ui.txt
python -m streamlit run scripts/research_ui.py --server.address 127.0.0.1 --browser.gatherUsageStats false
```

启动后浏览器显示中文研究工作台。服务绑定本机地址，不对局域网开放。关闭启动终端即可结束服务。

## 操作顺序

1. 在左侧选择确定性合成数据，或上传行情CSV、来源元数据JSON、交易日历CSV并填写日历身份。
2. 设置窗口、评价周期、五/十组、Top N、周/月调仓及初始资金。
3. 点击运行研究。独立进程执行正式run_stage8入口，单次超时120秒。
4. 查看累计收益、最大回撤、最终资产和成交笔数。
5. 在研究图表页选择IC、RankIC、分组、净值、回撤等图表，阅读中文口径说明。
6. 在交易与数据页查看评分、目标、订单、成交及账户快照，支持按股票筛选。
7. 在完整报告页查看正式HTML；在参数与局限页核对输入和运行环境。
8. 在下载结果页准备ZIP，或单独下载CSV和JSON。

## 数据与运行记录

原始输入继续遵循第二阶段契约。每份上传文件最大20MB；真实数据仅保存在本机忽略的reports目录中，未自动发送到第三方。上传文件统一使用固定名称，避免使用原文件名构建路径。

每次运行使用时间加随机标识的新目录，不覆盖旧报告。运行记录读取reports下一层已有报告，并允许切换。失败可能留下部分输出；不会把失败目录当作已完成报告显示。历史报告只有HTML和summary均存在时才进入列表。

CSV页面最多显示前2000行，完整数据通过下载取得。ZIP保留HTML图片相对目录。界面中的完整报告预览只替换图片引用为嵌入图像，不修改原始HTML；预览内文件索引不能用于下载，应切换下载结果页。

## 工程边界与后续方向

界面通过subprocess参数列表调用正式入口，不使用shell，不复制因子或账户逻辑。当前为单机轻量展示，不是多人任务调度平台；计算同步等待，未提供取消、后台队列、访问控制和大文件流式处理。现有PNG图表标题沿用原版本，界面提供中文标题和说明。

合成行情及教学日历不证明市场有效性，未知状态不等于可交易。真实数据覆盖、历史股票池、退市样本、公司行动及撮合限制仍沿用原报告披露。

本增强未改变前八阶段已验收基线，不会自动提交推送GitHub。Python 3.10兼容性需针对Streamlit可选依赖另行实测，不能用原166项测试记录代替。

启动时发现默认服务位置被项目一工作台占用，未停止或修改项目一，改用项目二独立服务位置成功打开。可在启动命令末尾增加`--server.port 8519`避免同机冲突。此次新增界面源文件、可选依赖及本说明，修改README；研究输出保存在忽略的reports目录。未提交推送GitHub，未操作数据库。
