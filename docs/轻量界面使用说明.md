# 多因子选股与量化策略研究系统：网页使用教程

本教程只介绍本系统的安装、启动、页面操作、数据上传与结果下载，不包含面试讲稿或演示案例。配套文件为《系统网页使用教程.pdf》。

## 一、安装与启动

需要Python 3.10或以上版本。打开项目根目录（含README、scripts、src的目录），使用独立环境安装：

```powershell
python -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements-ui.txt
.venv\Scripts\python.exe -m streamlit run scripts/research_ui.py --server.address 127.0.0.1 --server.port 8519 --browser.gatherUsageStats false
```

按启动终端提示进入浏览器页面，页面名称为“多因子研究工作台”。保持终端运行；停止系统时在启动终端按Ctrl+C。仅关闭浏览器页面不一定停止程序。指定服务位置被占用时，更换未使用的值，不要停止不相关项目。

研究核心有Python 3.10和3.12运行记录；网页依赖尚未单独完成Python 3.10矩阵验证。安装依赖应使用启动系统的同一个解释器。

## 二、创建研究

1. 左侧“新建研究”选择数据来源。
2. 选择“确定性合成数据”时无需上传文件；选择“上传外部CSV”时按第五节准备资料。
3. 设置参数，点击“运行研究”。
4. 等待“研究完成，结果已保留为独立运行记录”提示。
5. 在“查看研究记录”确认当前选择的是需要查看的记录。

| 参数 | 默认值与限制 | 用途 |
|---|---|---|
| 因子回看窗口（交易日） | 默认20；2～252 | 三个因子共用的历史窗口 |
| 未来收益评价周期 | 默认5、20；可选1、5、10、20、60 | 至少选一项，仅用于事后评价 |
| 因子分组数 | 5或10 | 按因子值划分股票组 |
| 选股数量Top N | 默认5；1～100 | 有效候选不足时剩余资金留现金 |
| 调仓频率 | 每周或每月 | 生成周期末信号和下一交易日执行计划 |
| 初始资金（元） | 默认100000；1000～100000000 | 共享现金账户的起始资金 |

当前网页不提供因子权重、方向、截尾比例、成本和滑点编辑器。使用三因子等权、1%/99%截尾、横截面Z-score及正式入口成本规则。确切参数通过“参数与局限”核对。未来收益周期不改变当时选股信息。

运行时同步等待，单次上限120秒；没有后台队列和取消按钮。每次运行使用独立记录，不覆盖旧结果。

## 三、查看结果

### 3.1 顶部指标和研究记录

顶部显示累计收益、最大回撤、最终资产和成交笔数。最终资产包含持仓市值，不等于现金；成交笔数不等于盈利笔数。不可计算的指标会显示“不可计算”。

通过“查看研究记录”切换历史结果。切换后先确认记录名称，再比较参数和指标，不要混用不同运行的数据。

### 3.2 研究图表

在“研究图表”页签的“选择图表”中切换：

| 图表 | 用途与注意事项 |
|---|---|
| IC时间序列 | 因子与未来收益的线性相关性，不是收益率 |
| RankIC时间序列 | 排名相关性，不是胜率 |
| IC分布 | 相关系数分布；多日标签重叠，不代表独立样本 |
| 因子相关性 | 原始因子每日截面相关性的时间均值 |
| 分组累计收益 | 非重叠区间研究统计，不是可执行账户净值 |
| 高低组收益差 | 未计融券、保证金与执行成本的研究指标 |
| 组合净值 | 实际模拟账户归一化资产，初始水平为1 |
| 组合回撤 | 相对历史资产峰值的跌幅 |
| 目标与实际换手 | 目标为含现金半L1距离；实际为双边成交金额/调仓前资产 |
| 订单状态 | 按执行日统计状态数量，不表示成交金额 |

PNG图内部分标题和图例仍为英文，网页提供中文名称及口径说明。数据不足时图中可能有空白或断点，不会自动补齐缺失收益。

### 3.3 交易与数据

先选择“数据表”。存在股票代码列时，可使用“筛选股票”查看单只股票。页面最多显示前2000行，完整内容需下载。

| 数据表 | 主要用途 |
|---|---|
| 股票评分 | 查看综合分数、排名和有效标记 |
| 目标权重、目标变化、调仓计划 | 查看计划配置、增减和信号/执行日期 |
| 订单 | 查看请求数量、实际数量、状态和原因 |
| 成交 | 查看实际数量、价格、佣金、税费与滑点 |
| 账户快照、最终持仓、净值明细 | 查看现金、总资产、持仓与收益路径 |
| 每日IC、IC汇总、分组汇总 | 查看因子评价及样本状态 |
| 未来收益标签 | 查看评价入口、出口与收益；不能用于当时选股 |
| 行情面板 | 查看日期对齐后的原始行情和状态 |

评分不是预期收益；目标权重不是成交持仓；订单不是成交。没有此类记录时页面会提示，不代表文件损坏。

### 3.4 完整报告

“完整报告”页签预览当前记录的正式HTML报告，包括数据说明、公式、因子评价、组合绩效、图表、参数和限制。

预览中的文件索引不用于下载。请到“下载结果”获取完整文件。预览不修改原始报告。

### 3.5 参数与局限

核对数据来源、是否合成数据、研究参数、交易成本、运行环境和日历身份。界面显示的“最近一次运行日志”可能不是当前选中的历史记录，需按提示区分。

## 四、下载与保管

1. 打开“下载结果”。
2. 点击“准备完整下载包”。
3. 出现按钮后点击“下载完整研究结果ZIP”。
4. 解压整个ZIP，保持HTML与charts图片目录的相对位置。
5. 只需摘要时点击“下载运行摘要”；只需表格时先“选择CSV下载”，再点击“下载所选CSV”。

运行结果和上传文件保存在本机，系统不自动提交GitHub。下载包可能包含原始行情，分享前核查许可。当前网页没有研究记录删除或重命名按钮。

## 五、上传外部行情

左侧选择“上传外部CSV”，必须同时提供“行情CSV”“来源元数据JSON”“交易日历CSV”，并填写“日历来源”和“日历版本”。每份文件最多20MB。

### 5.1 行情CSV

```csv
symbol,trade_date,open,high,low,close,volume,amount
000001,2025-01-02,10,12,9,11,1000,11000
```

要求：日期为YYYY-MM-DD；股票代码为文本；股票/日期组合唯一；有效价格为正；成交量和成交额非负；开高低收关系合法。缺失留空，不用0代替。单位固定为CNY、股、CNY，不自动换算。

### 5.2 来源元数据JSON

下面只说明文件结构，需换成实际来源和范围：

```json
{
  "source": "用户自备行情",
  "market": "CN",
  "price_type": "未复权",
  "data_as_of": "2025-01-06",
  "is_synthetic": false,
  "universe_description": "填写实际证券范围和筛选方法",
  "includes_delisted": null,
  "price_unit": "CNY",
  "volume_unit": "股",
  "amount_unit": "CNY"
}
```

price_type支持未复权、前复权、后复权；is_synthetic必须真实反映是否合成；includes_delisted未知时填null。系统尚无完整公司行动处理，复权价格不应直接视为真实成交价。

### 5.3 交易日历CSV

```csv
trade_date
2025-01-02
2025-01-03
2025-01-06
```

只能有trade_date一列，不重复，只包含开放交易日。行情须在日历内，行情和日历不能晚于data_as_of。日历来源和版本需填写可追溯名称。系统不会自动认证交易所日历；报告中的calendar_is_exchange_verified当前固定为false。

历史长度应足以覆盖因子回看、未来评价及调仓边界；默认预处理至少5个合格样本，常量截面不能标准化。数据读取成功不保证存在有效因子、IC或成交。网页没有逐日上市/停牌状态文件上传入口。

## 六、常见问题

| 情况 | 处理方法 |
|---|---|
| 找不到Streamlit或其他依赖 | 用实际启动系统的解释器安装requirements-ui.txt |
| 运行提示资料不全 | 确认外部模式三份文件、日历来源和版本齐全，至少选择一个评价周期 |
| 运行失败或超时 | 展开“运行错误”，按错误修正数据或减少规模；重新运行会生成新记录 |
| 历史前段没有评分或持仓 | 检查窗口长度、缺价、少样本和零方差，不要把缺失值改成0 |
| 尾部未来收益缺失 | 尚无完整未来区间，不补造数据 |
| 看到了另一组结果 | 检查“查看研究记录”和“参数与局限”，不要仅看最近日志 |
| CSV代码前导零不见 | 表格软件可能自动识别为数字，导入时按文本处理 |
| 下载报告图片不显示 | 解压完整ZIP并保持目录结构，不只复制HTML |
| 界面提示弃用警告 | 当前接口存在已知升级提示，与业务错误区分；安装依赖时遵循项目版本范围 |

失败可能留下部分文件；只有报告HTML和摘要同时存在的记录才会列入记录选项，列表存在不等于额外通过了完整性审计。当前页面不提供重试接续或失败文件清理功能。

## 七、适用边界

这是单机研究系统，不提供实盘、账号管理、多人调度或公网部署。合成数据仅用于流程检查。缺少完整历史成分股、退市和公司行动资料，未消除幸存者偏差；未完整建模涨跌停、成交量和融券，未接入数据库。研究结果不构成投资建议。
