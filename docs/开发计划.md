## 第一阶段拟确认参数

- 主标签：下一交易日开盘到H个交易日之后开盘；H=5/20分别报告。
- 预处理：同日1%/99%截尾，ddof=0标准化；常量或少样本置无效。
- 因子方向：动量+、低波-、均线偏离-，均为研究假设。
- 组合：每个家族一个预先配置窗口，默认等权；完整因子样本。
- 并列分组：平均秩分位，允许空组；排名Top N另用稳定代码顺序处理边界并披露。

以上是提案而非已批准业务规则，未写入可执行实现。
