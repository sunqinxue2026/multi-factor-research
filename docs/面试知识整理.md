# 第一阶段面试知识

## 为什么分开特征和标签
特征在t收盘已知，标签依赖未来，仅用于评价。排名和标准化只接收特征；标签表保存入口/出口日期，便于检查时间关系。追加未来数据不能改变历史特征，可能使原无效的尾部标签变有效。

## 时间序列与横截面
动量/波动/均线偏离按symbol回看历史；Z-score、分组、IC按同一天比较多只股票。项目一add_indicators中的按股票滚动方式可参考，但不能直接把它的时间序列统计当截面标准化。

## IC与RankIC
Pearson评价数值线性关系；Spearman先平均秩再评价秩关系，对单调关系敏感。常量无定义，少样本相关很不稳定。多日标签重叠时观测不独立，不能用朴素t值包装显著性。

## 因子含义
动量假设趋势延续，低波假设低风险偏好，反转假设偏离回归；方向是事前配置并可证伪，不是经济定律。20与60日是同一家族不同参数，不能事后用全样本选最好窗口再报告样本内成绩。

## 数据结构与复杂度
长表date/symbol唯一键便于审计，按股票滚动、按日期排名。M行排序O(M log M)，一般滚动指标O(M)，每日排名O(T*S log S)。全日历面板空间O(TS)，稀疏行情对齐可能显著膨胀，后续需依据数据规模测量。

## 替代与追问
- 为什么不直接用项目一引擎？实际源码显式拒绝多股票且账户不加仓；需扩展契约而非伪装兼容。
- 为什么不直接每天复利未来5日收益？收益区间重叠，重复计入持仓收益；用非重叠批次或日度组合净值。
- 如何处理停牌？区分不可交易与估值，未知状态不能当作确定停牌；不可成交不等于资产归零。
- 如何避免幸存者偏差？需时点股票池及退市数据；缺少则披露，不能靠算法宣称解决。
- 为什么不用机器学习？先用透明线性等权基准，建立正确数据时序和样本外评价再增加复杂模型。

## 第一阶段新增追问

- 为什么有收盘价还不能认定可交易？价格是行情观察，真实成交还受停牌、涨跌停、流动性等影响；unknown不等于可交易。
- 项目一哪段代码证明需要适配？engine/backtest.py的run检查symbol.nunique()!=1即报错，Snapshot只有单股数量和价格；绩效分析也不是组合交易配对。
- 日历对齐的代价？M条行情排序O(M log M)，完整T×S面板内存O(TS)；K个因子全量存储O(KTS)，不能只报稀疏输入行数空间。
- IC计算复杂度？Pearson每截面约O(S)，RankIC需排名通常O(S log S)；截尾分位计算的复杂度取决于具体库算法，排序实现通常O(S log S)，不能无依据声称最优。
- 有何替代？宽表便于矩阵研究但元数据和状态对齐易错；长表便于来源追踪与分组操作。严格缺失传播较保守；填充方案必须另行验证对收益和停牌的影响。

以上对应真实项目一接口和项目二设计；项目二尚无业务实现，面试不能称这些模块已经完成。

## 第二阶段真实实现讲解
- read_market_csv：一次读取字节，同时解析CSV及计算SHA-256，避免摘要与解析对应不同输入；symbol使用字符串保留前导零。
- validate_market_frame：深拷贝、日期严格解析、数值有限性及OHLC关系检查、唯一键检查、稳定排序，拒绝非法值而非悄悄变成缺失。
- build_calendar_panel：MultiIndex.from_product构造股票×市场交易日，reindex补行不补值；index.isin标记原始行。可空布尔保留未知状态，不用False冒充缺少证据。
- PanelResult.cross_section：按日期切片并返回副本，支持下一阶段横截面研究；输入与结果修改隔离有测试。
- 复杂度：M条输入排序O(M log M)，T日S股面板分配/空间O(TS)；CSV原始字节和输入表额外空间O(B+M)，B为文件字节数。横截面筛选扫描面板O(TS)，可后续建立日期索引优化；未做吞吐基准。
- 替代：宽表便于向量运算但状态元数据易错位；稀疏表节约空间但滚动窗口可能跨过缺失交易日。当前选完整长表换取可审计性。
- 面试追问“零成交是否停牌”：不能，仅保留观测到的零，停牌需要外部逐日证据。
- 面试追问“怎样验证不泄漏”：test_append_future_keeps_historical_panel_unchanged追加未来行及日历后，逐字段比较历史面板相同。这只覆盖数据层，不代表尚未实现的因子和策略已通过泄漏验证。
- 面试追问“前后缺失是否未上市”：不能推断，代码标unknown，需要时点上市及退市资料。

## 第三阶段：结合实际因子代码
calculate_factors使用groupby逐股票回看，shift定位N日前价格，rolling count约束N+1连续收盘，pct_change(fill_method=None)不填充收益，rolling std(ddof=1)计算波动；均线偏离close/rolling mean-1尚未取负。
100、110、99、99：3日动量-1%；日收益10%、-10%、0%，样本波动10%；偏离-11/308。test_hand_calculated_values_and_raw_direction直接断言。
未来不变性测试追加及修改未来行后逐字段比较旧历史，不证明幸存者偏差消除。valid不等于tradable；明确停牌有价仍保留统计与状态。
复杂度：P行、S股票、K窗口，滚动约O(KP)，状态逐股票扫描额外O(SP)，输出L=3KP排序O(L log L)，空间约O(L+P)。可预分组状态、分块导出，但无性能实测不承诺加速。面试追问与替代实现详见第三阶段验收报告第7至9节。

## 第四阶段：结合preprocessing.py讲解

preprocess_factors先校验键和值，保留源valid/reason，按日期/因子/窗口独立groupby，只对research_eligible样本quantile(interpolation="linear")、clip、std(ddof=0)，最后乘direction。少于5只和std=0均不填0。

手算：关闭截尾时[-2,-1,0,1,2]均值0、方差2，z=x/sqrt(2)。[0,1,2,3,100]用25/75分位截尾变为[1,1,2,3,3]，均值2、方差0.8。对应test_hand_zscore_no_clip_and_input_unchanged与test_linear_quantile_clipping_exact_values。

时间序列因子描述股票自身历史，横截面标准化描述当日相对其他股票的位置，不能混用全样本统计。ddof=0是当前截面尺度口径，原波动率ddof=1是日收益样本估计。正向高分是研究约定，不证明预测能力；因子有效性要在第五阶段用正确时点标签评价，不以标准化通过替代IC。

未来不变性由test_date_factor_window_isolation_and_order覆盖追加/修改未来日期；不证明历史股票池或复权数据时点无偏。股票池资料不足仍披露幸存者偏差。未知停牌/上市允许研究但不是执行资格，执行层必须再校验。

R行排序O(R log R)，分位数保守估sum O(n_g log n_g)，空间O(R+G)加副本。可选MAD、秩标准化、向量化/分块，但需先测瓶颈，不能改变规则。面试官追问零方差时结合preprocess_reason回答：无辨识度不是平均水平，保留缺失并阻止后续评分。

## 第五阶段：标签、相关性和分组

真实实现：analysis.py的build_forward_returns使用负shift构造事后标签，analyze_factors只消费标签进行评价，不修改因子。入口t+1开盘，出口t+1+H开盘；测试以每天1%上涨验证H=2收益1.01²−1。

IC是Pearson线性相关，RankIC是平均秩后Pearson；[0,0,1,2,2]对严格递增收益RankIC=sqrt(0.9)。原始和定向IC分别报告，不能把方向翻转当作原始alpha证据。ICIR用有效日期样本标准差，重叠标签有相关性，不能直接宣称显著。

分组必须先用当日因子决定成员，不能未来缺价后重排；标签缺失整组无效。H日重叠收益不每日复利；固定首日锚点每H日取样，初期预热后缺口阻断。成员均值不含真实现金、费用、停牌成交或融券，因此不等同组合回测。

算法：标签空间O(STK)，因子与H合并O(RK)，截面排名保守O(sum n log n)，循环赋值和累计状态扫描有开销。替代为错位子组合、HAC显著性检验或真实组合引擎，均需额外资金/统计规则。面试结合test_ic_summary_sample_std_and_positive_ratio解释IC序列均值1/7、正值比例4/7；结合test_group_missing_label_keeps_members_and_breaks_curve解释缺失与审计。
