## 1. 本阶段目标

在第三阶段FactorResult上实现同日横截面预处理，保持数据来源、原始因子和市场状态可追溯，为后续IC和多因子评分提供明确输入。经负责人确认的基线：1%/99%线性分位数截尾、最少5个研究样本、总体标准差ddof=0、动量+1/波动率−1/均线偏离−1。排除明确未上市或停牌，未知状态允许研究并披露，不将其视为投资资格。

本阶段不计算未来收益、IC、股票排名、组合、调仓或账户绩效。

## 3. 已实现的功能

### 3.1 接口和契约

`preprocess_factors(factors, *, quantiles=(0.01, 0.99), min_samples=5, directions=None)`接收FactorResult，返回PreprocessingResult。默认配置没有隐藏在脚本中，API和脚本共享规则。quantiles=None关闭截尾；方向可完整自定义，当前数据中每个因子都必须有明确方向。

拒绝空输入、缺列、重复联合键、日内/带时区日期、非法股票和窗口、非布尔valid、非法数值、无限值、有效标记但值缺失，以及重复预处理字段。状态缺列时新增可空布尔未知值；非法状态字符串拒绝。当前API要求调用方按类型约定传递容器，不承诺所有错误对象均统一为ValueError。

### 3.2 样本和原始信息

原始valid/reason仍表示第三阶段价格窗口有效性。新增research_eligible表示可参加本次研究截面：原始有效，且无明确未上市/停牌。tradable=False本身不额外过滤；因缺失开盘等情况阻止执行，不一定使历史收盘价格统计失去研究意义，执行阶段须另行检查。

原始无效行保留，preprocess_reason=raw_invalid；原始原因仍在reason。明确状态排除记explicit_status_excluded。未知状态参与时在审计中计数，不冒充时点可投资股票池。

### 3.3 处理顺序与输出

按trade_date、factor、window独立分组；N不足记insufficient_cross_section。样本足够后按线性分位数截尾，计算ddof=0均值/标准差。零标准差记zero_variance，不填零。有限非零的小方差不使用任意绝对阈值排除；统计或标准化非有限则报错。

逐行保留value、valid、reason及状态，新增clipped_value、zscore、direction、oriented_value、was_clipped、research_eligible、preprocess_valid、preprocess_reason。少样本时不计算阈值和截尾值；零方差时仍保留截尾值但标准化值为空。

审计表逐截面记录input_count、eligible_count、raw_invalid_count、status_excluded_count、unknown_status_count、lower_bound、upper_bound、mean、std、clipped_count、valid_count、status。unknown_status_count仅统计合格研究样本中至少一项上市/停牌未知的行。未截尾时边界为空，不把样本最小最大值冒作截尾阈值。

参数保留原始因子参数、日历来源/版本和输入摘要。输入做深副本；结果内部DataFrame和字典仍可变，不宣称不可变架构。

## 5. 核心数据结构、算法和公式

PreprocessingResult含frame、audit、parameters、file_sha256、calendar_source、calendar_version。逐行键为symbol/trade_date/factor/window；统计键不含symbol，即同日横截面。

线性分位数位置h=(n−1)q，在相邻顺序统计量之间插值。截尾x'=min(max(x,L),U)。均值μ=sum(x')/n；σ=sqrt(sum((x'−μ)^2)/n)；z=(x'−μ)/σ；oriented_value=direction*z。

手算：[-2,-1,0,1,2]平方和10，除以5得到方差2，因此z为[-sqrt(2),-1/sqrt(2),0,1/sqrt(2),sqrt(2)]。原始波动率ddof=1与本阶段标准化ddof=0用途不同，不混用。

对R行按联合键排序O(R log R)；各组分位数保守按排序估计sum O(n_g log n_g)，均值/裁剪为线性。输出空间O(R+G)，G为截面数；DataFrame副本和分组增加实际峰值内存。该复杂度为估计，不是基准数据。

## 6. 采用该方案的原因

1. 复用FactorResult，不重复因子计算、不改变旧接口。
2. 按同日因子和窗口统计，阻止跨日期和不同定义混算；不使用未来收益选择方向。
3. 先截尾再标准化，降低极端值对均值/标准差的支配；保留原始值可审计。
4. 少样本和常量没有可解释的相对差异，保留无效而不是填0。
5. 未知状态允许研究但记录，不把有限资料伪装成可投资股票池。
6. 分开research_eligible和preprocess_valid，表达“可参加样本”与“截面处理成功”的不同含义。

逐截面循环、DataFrame索引赋值、原表深复制和CSV导出可能限制大规模运行。先测量真实研究规模的分组、分位数、赋值及内存，再考虑向量化、按日期分块、列式结果存储。必须保留相同分位数插值、状态、缺失、排序和浮点容差回归。约1秒的极小合成样本不是全市场性能基准，不承诺加速倍数。

## 9. 常见技术追问与回答思路

- 为什么不用全样本标准化？结合GROUP_KEYS说明每次只统计同日同因子同窗口，未来样本不能参与历史统计。
- 时间序列与横截面区别？第三阶段逐股票沿时间回看；第四阶段在固定日期比较股票，不是给单只股票做全历史Z-score。
- 为什么先截尾？结合test_linear_quantile_clipping_exact_values说明100裁为3的手算例，注意极端值不一定错误，所以保留value和标记。
- ddof为什么不同？因子波动率估计日收益样本标准差；这里按所选截面总体做相对尺度变换，口径写入parameters。
- 所有值相同时填0行不行？会掩盖无辨识度，代码明确zero_variance，后续不参与评分。
- 怎样防未来泄漏？日期分组、不引入标签，并通过追加修改未来的历史不变性测试；不能据此消除股票池和复权修订偏差。
- 为什么低波和负偏离取负？统一高分优先的假设，参数显式记录；未用收益检验，不能宣称假设成立。
- tradable=False为什么也可能研究？价格统计与成交能力不同。无开盘报价等阻止执行不自动否定有效收盘历史；明确停牌/未上市已排除。
- 怎样知道结果正确？给出手算、审计计数、导出均值0/std1以及两版本运行证据，不只说退出码0。
